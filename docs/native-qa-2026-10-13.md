This draft is based on PR #37 (`b7f2de8e11de9064ef667789c3fb7eed4d73afb5`). Integration tests additionally used PR #38 (`d40410d044335343920fdf90ae01c6d3a0519f83`) in a local-only combined tree. No remote merge or production connection was performed. PR #38 changes are not included in this draft.

## Bugs fixed

- Photo upload Edge Function: a string constant named `URL` shadowed the global `URL` constructor, causing origin parsing to reject legitimate requests. Rename it to `SUPABASE_URL` and regression-test the actual handler.
- Buyer reservation display: `new Intl.DateTimeFormat(...).format(...)` combined `timeStyle: "short"` with `timeZoneName: "short"`, which throws `TypeError: Invalid option : option` in the tested Node runtimes. Use explicit hour/minute components with the timezone name. Tests cover UTC, Toronto summer/winter, Vancouver and midnight.
- Exact local recovery callbacks: Next's URL normalization changed literal `127.0.0.1` into `localhost`. Skip normalization only for the explicitly validated loopback-isolation mode.
- Replace an existing potentially expensive nested source-test regex with TypeScript AST traversal while preserving its checkout assertions.

The native-only URL/CSP/Edge configuration remains fail closed, rejects the known production target/key, and preserves hosted defaults and MFA/permission checks. See [isolated setup](isolated-supabase-testing.md).

## Executor limitations

Official Supabase CLI 2.120.0 native startup requires Unix-domain sockets unavailable in this executor. Official checksum-verified service artifacts were launched with supported TCP settings instead. Auth, PostgreSQL/PostgREST, Storage, Edge and Next were exercised as real services. This is not a claim that stock CLI startup passed.

Chromium terminated before page load with `socket() failed: Operation not permitted` in its process-singleton code. No browser security bypass was used. Browser rendering, interaction, accessibility and browser TLS remain unverified. Realtime started but channel subscription failed with executor `EPERM`; no successful realtime roundtrip is claimed.

The read-only HTTPS image proxy was trusted only by the individual QA HTTP client. Production TLS validation and system/browser trust settings were unchanged. External AI, postal/carrier, cron privileged execution and payment sandbox integration were not verified by this run.
